# you-are-routered

## Context

The goal is to design a Mixture of Expert from scratch with PyTorch to rout demands and a RAG. 
 
## Features 

This application should be able to : 
- ingest data (pdf, etc..) 
- chunk documents
- input text questions 
- pick retrieval experts
- retrieve candidates
- update rank candidates
- construct context
- generate an smooth answer 
- show citations from documents
- record routing and evaluation metrics
